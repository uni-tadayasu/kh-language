        すべてのコマンドと実行例 ↗

Mac・Linuxで使う

        
複数ページの出力には、KHのコマンドライン版を使えます。Linux x64用の実行ファイルと、Mac・Linuxでビルドできるソースを同梱しています。

        

          ブラウザー版を開く ↗
          ↓ Mac・Linux向けCLIをダウンロード
        

        
CLIの使い方
ZIPを展開してターミナルで開き、Cコンパイラとmakeを使ってビルドします。
make
./kh run examples/Console/Hello.kh
./kh web examples/Website/index.kh my-site
