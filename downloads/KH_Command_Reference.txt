KH言語 0.3 コマンドリファレンス
F1で開く / Escで閉じる / Ctrl+Aで全選択 / Ctrl+Cでコピー

■ 基本の書き方
KHのソースはUTF-8の .kh ファイルです。命令は1行ずつ書き、英語の命令名は小文字で入力します。インデントは読みやすさのために使えます。

【say】
書き方  say 式
式の結果を1行表示します。コンソールを選んで実行すると確認できます。
対応  Windows IDE・CLI・ブラウザー版

入力例
say "こんにちは、KH！"
say 1 + 2

結果・動作
こんにちは、KH！
3

【変数への代入】
書き方  名前 = 値
名前の右側に値や式を書きます。同じ名前にもう一度代入すると値が変わります。変数名・関数名・引数名には日本語や英字が使えます。名前の先頭には文字か _、2文字目以降には数字も使えます。大文字と小文字は区別されます。
対応  Windows IDE・CLI・ブラウザー版

入力例
人数 = 2
人数 = 人数 + 1
say 人数

結果・動作
3

【コメント】
書き方  # コメント
行頭や命令の後ろに # を置くと、同じ行の残りはコメントになります。二重引用符の中の # は文字として表示されます。
対応  Windows IDE・CLI・ブラウザー版

入力例
# この行はメモです
say "#KH" # この部分は表示されません

結果・動作
#KH

【数値】
書き方  0、42、3.5、.5
整数と小数は半角数字で書きます。小数点は .、負の値には先頭に - を使います。
対応  Windows IDE・CLI・ブラウザー版

入力例
say 42
say 3.5
say .5

結果・動作
42
3.5
0.5

【文字列】
書き方  "文字列"
文字列は半角の二重引用符で囲みます。文字列内では \n は改行、\t はタブ、\r は復帰、\b は後退、\f は改ページ、\" は引用符、\\ は逆斜線、\/ はスラッシュ、\uXXXX は4桁の16進Unicode表記です。
対応  Windows IDE・CLI・ブラウザー版

入力例
say "上の行\n下の行"
say "\"KH\"\u8A00\u8A9E"

結果・動作
上の行
下の行
"KH"言語

【真偽値】
書き方  true / false
条件や比較の結果を表します。true は真、false は偽です。引用符を付けた "true" は文字列です。
対応  Windows IDE・CLI・ブラウザー版

入力例
say true
say false

結果・動作
true
false

【値なし】
書き方  return または関数の終端
値を指定せず return した関数や、値を返さず end まで進んだ関数は値なしを返します。say では null と表示されます。
対応  Windows IDE・CLI・ブラウザー版

入力例
function 完了()
    return
end
say 完了()

結果・動作
null

■ 演算子
括弧を除く優先順位は、高い方から単項 + -、* / %、加減算 + -、大小比較、等値比較、not、and、or です。式を読む順番が分かりにくいときは括弧を使えます。

【括弧】
書き方  (式)
括弧内の式を先に計算します。
対応  Windows IDE・CLI・ブラウザー版

入力例
say 2 + 3 * 4
say (2 + 3) * 4

結果・動作
14
20

【加算・文字列連結】
書き方  左 + 右
両方が数値なら足し算です。片方が文字列なら、もう片方を表示用の文字にして連結します。
対応  Windows IDE・CLI・ブラウザー版

入力例
say 2 + 3
say "人数 " + 3 + "人"

結果・動作
5
人数 3人

【減算・単項符号】
書き方  左 - 右 / -値 / +値
数値の差を求めます。数値の前の - は符号を反転し、前の + はその値を返します。
対応  Windows IDE・CLI・ブラウザー版

入力例
say 10 - 3
say -5
say +5

結果・動作
7
-5
5

【乗算】
書き方  左 * 右
2つの数値を掛けます。
対応  Windows IDE・CLI・ブラウザー版

入力例
say 6 * 4

結果・動作
24

【除算】
書き方  左 / 右
数値を割ります。結果は小数になり、0で割るとエラーです。
対応  Windows IDE・CLI・ブラウザー版

入力例
say 7 / 2

結果・動作
3.5

【余り】
書き方  左 % 右
数値を割った余りを求めます。右が0ならエラーです。
対応  Windows IDE・CLI・ブラウザー版

入力例
say 7 % 3

結果・動作
1

【等しい・異なる】
書き方  左 == 右 / 左 != 右
値と種類の両方が一致すれば == は true になります。!= は逆の結果を返します。
対応  Windows IDE・CLI・ブラウザー版

入力例
say 2 == 2
say 2 == "2"
say "春" != "夏"

結果・動作
true
false
true

【大小比較】
書き方  左 < 右 / 左 <= 右 / 左 > 右 / 左 >= 右
数値同士を比較します。<= は以下、>= は以上です。
対応  Windows IDE・CLI・ブラウザー版

入力例
say 3 < 5
say 5 <= 5
say 3 > 5
say 5 >= 5

結果・動作
true
true
false
true

【両方が真】
書き方  左 and 右
左と右が真なら true です。左が false の場合は、右側を実行せず false を返します。
対応  Windows IDE・CLI・ブラウザー版

入力例
say true and true
say false and 未定義

結果・動作
true
false

【どちらかが真】
書き方  左 or 右
どちらかが真なら true です。左が true の場合は、右側を実行せず true を返します。
対応  Windows IDE・CLI・ブラウザー版

入力例
say false or true
say true or 未定義

結果・動作
true
true

【真偽の反転】
書き方  not 式
true を false、false を true にします。比較と組み合わせるときは括弧を付けると明確です。
対応  Windows IDE・CLI・ブラウザー版

入力例
say not false
say not (3 < 5)

結果・動作
true
false

■ 分岐・繰り返し・関数
分岐・繰り返し・関数は end で閉じます。条件には true または false になる式を書きます。

【if】
書き方  if 条件 … end
条件が true のとき、if から end までの命令を実行します。条件に数値や文字列を置くとエラーです。
対応  Windows IDE・CLI・ブラウザー版

入力例
人数 = 3
if 人数 >= 2
    say "複数人です"
end

結果・動作
複数人です

【else】
書き方  if 条件 … else … end
if の条件が false の場合に実行する命令を、else の後ろに書きます。else は省略できます。
対応  Windows IDE・CLI・ブラウザー版

入力例
年齢 = 12
if 年齢 >= 18
    say "成人"
else
    say "未成年"
end

結果・動作
未成年

【repeat】
書き方  repeat 回数 … end
指定した回数だけ繰り返します。回数は0から10,000までの整数です。0回なら中の命令を実行しません。
対応  Windows IDE・CLI・ブラウザー版

入力例
番号 = 1
repeat 3
    say 番号
    番号 = 番号 + 1
end

結果・動作
1
2
3

【function】
書き方  function 名前(引数1, 引数2) … end
まとまった処理に名前を付けます。関数定義はファイルの最上位に書きます。引数がなければ () と書きます。関数の中で代入した変数は呼び出しごとのローカル変数です。外の変数は読み取れます。
対応  Windows IDE・CLI・ブラウザー版

入力例
function 合計(左, 右)
    return 左 + 右
end
say 合計(3, 4)

結果・動作
7

【関数の呼び出し】
書き方  名前(値1, 値2)
定義と同じ数の値を順に渡します。呼び出しの結果は式に使えます。表示などを行う関数は、呼び出しだけを1行に書いて実行できます。
対応  Windows IDE・CLI・ブラウザー版

入力例
function 挨拶(名前)
    say "こんにちは、" + 名前
end
挨拶("世界")

結果・動作
こんにちは、世界

【return】
書き方  return 式 / return
関数の実行をそこで終えます。式があれば呼び出し元に値を返します。
対応  Windows IDE・CLI・ブラウザー版

入力例
function 二倍(数)
    return 数 * 2
end
結果 = 二倍(6)
say 結果

結果・動作
12

【end】
書き方  end
直前に開いた if、repeat、function を閉じます。入れ子にした場合は、内側のブロックから順番に閉じます。
対応  Windows IDE・CLI・ブラウザー版

入力例
repeat 2
    if true
        say "実行"
    end
end

結果・動作
実行
実行

■ ウェブ制作コマンド
ウェブ用コマンドには文字列を渡します。Windows IDEのF8、CLIのweb、またはブラウザー版の「ウェブページ」で使います。

【page（トップページ）】
書き方  page("タイトル", "説明")
index.html を作り、以後の見出しや本文をこのページに追加します。説明は見出しの下とHTMLのメタ説明に使われます。説明を省略したいときは空文字を渡します。
対応  Windows IDEのHTML出力・CLIのweb・ブラウザー版のウェブページ

入力例
page("活動案内", "地域の活動を紹介します。")

結果・動作
「活動案内」と説明が表示されます。

【page（追加ページ）】
書き方  page("about.html", "タイトル", "説明")
指定した名前で追加ページを作ります。最初を半角英数字にし、残りに半角英数字・ハイフン・アンダースコアを使って .html で終えます。同名のページは作れません。
対応  Windows IDEのHTML出力・CLIのweb・ブラウザー版のウェブページ

入力例
page("ホーム", "活動の紹介です。")
link("私たちについて", "about.html")
page("about.html", "私たちについて", "地域で活動しています。")
link("ホームへ", "index.html")

結果・動作
「私たちについて」を押すと紹介ページに移ります。Windows IDEとCLIは個別HTMLを生成します。ブラウザー版は単一HTML内でページを切り替えます。

【heading】
書き方  heading("見出し")
現在のページに見出しを追加します。通常は h2、section() 内では h3 を生成します。ページの主見出し h1 は page() のタイトルです。
対応  Windows IDEのHTML出力・CLIのweb・ブラウザー版のウェブページ

入力例
page("読書会", "")
heading("次回の開催")

結果・動作
「読書会」の下に「次回の開催」という見出しが表示されます。

【text】
書き方  text("本文")
現在のページに段落を追加します。<strong> などを書いても、画面には入力した文字列として表示されます。
対応  Windows IDEのHTML出力・CLIのweb・ブラウザー版のウェブページ

入力例
page("案内", "")
text("会場は2階です。")

結果・動作
「会場は2階です。」が段落として表示されます。

【link】
書き方  link("リンクの文字", "URL")
現在のページにリンクを置きます。別ページの相対パス、https:// や http:// のURL、mailto:、#から始まるページ内リンクを使えます。
対応  Windows IDEのHTML出力・CLIのweb・ブラウザー版のウェブページ

入力例
page("会場案内", "")
link("紹介ページ", "about.html")
page("about.html", "紹介ページ", "開催場所の説明です。")

結果・動作
「紹介ページ」をクリックすると、追加したページに移ります。

【image】
書き方  image("画像のパスまたはURL", "画像の説明")
画像を置き、読み上げなどで使う代替テキストを指定します。ローカル画像は出力されたフォルダーに別途置きます。
対応  Windows IDEのHTML出力・CLIのweb

入力例
page("ギャラリー", "")
image("photo.jpg", "会場に飾った花")

結果・動作
出力先に photo.jpg を置くと画像が表示されます。

【section】
書き方  section("セクション名")
見出し付きのまとまりを開始します。下に書く本文などがそのまとまりに入り、section_end() で閉じます。
対応  Windows IDEのHTML出力・CLIのweb・ブラウザー版のウェブページ

入力例
page("工房", "")
section("営業案内")
text("土日に開館します。")
section_end()

結果・動作
「営業案内」の枠内に「土日に開館します。」が表示されます。

【section_end】
書き方  section_end()
一番内側の section() を閉じます。引数は不要です。次のページを作る前に、開いているセクションをすべて閉じます。
対応  Windows IDEのHTML出力・CLIのweb・ブラウザー版のウェブページ

入力例
page("工房", "")
section("予約")
text("予約は前日まで。")
section_end()
text("お問い合わせは受付へ。")

結果・動作
予約案内は枠内に表示され、問い合わせ案内は枠外に表示されます。

【button】
書き方  button("ボタンの文字", "表示するメッセージ")
押したときに、ボタンの下にメッセージを出す操作を作ります。
対応  Windows IDEのHTML出力・CLIのweb・ブラウザー版のウェブページ

入力例
page("イベント", "")
button("持ち物を見る", "筆記用具をお持ちください。")

結果・動作
「持ち物を見る」を押すと「筆記用具をお持ちください。」が表示されます。

【theme】
書き方  theme("#RRGGBB")
サイト共通のアクセント色を、# に続く6桁の16進数で指定します。ボタンや見出し周辺に反映されます。
対応  Windows IDEのHTML出力・CLIのweb・ブラウザー版のウェブページ

入力例
theme("#7356a8")
page("色の見本", "")
button("確認", "表示できました。")

結果・動作
ボタンやページ上部に紫色のアクセントが付きます。

【language】
書き方  language("ja")
サイト全体のHTMLに言語を設定します。省略時は ja です。日本語は ja、英語は en、米国英語は en-US などを使えます。本文は入力した言語で表示されます。
対応  Windows IDEのHTML出力・CLIのweb・ブラウザー版のウェブページ

入力例
language("en")
page("Welcome", "A short example.")

結果・動作
Welcome と表示され、生成HTMLの html 要素に lang="en" が付きます。

【css】
書き方  css("CSSの内容")
サイト共通の styles.css に指定したCSSを追記します。
対応  Windows IDEのHTML出力・CLIのweb

入力例
page("デザイン見本", "")
text("背景色が変わります。")
css("body { background: #fff1d6; }")

結果・動作
生成ページの背景色が薄いオレンジになります。

【script】
書き方  script("JavaScriptの内容")
サイト共通の app.js に指定したJavaScriptを追記します。追加したJavaScriptは生成したページをブラウザーで開くと実行されます。
対応  Windows IDEのHTML出力・CLIのweb

入力例
page("動作見本", "")
script("console.log(\"KHのページです\");")

結果・動作
生成ページを開くと、開発者ツールのコンソールに「KHのページです」と表示されます。

【use】
書き方  use "ファイル名.kh"
編集中の .kh と同じフォルダーのファイルを読み込み、その位置に展開します。ファイル名は半角英数字・ハイフン・アンダースコアで指定します。Windows IDEではメインの .kh を保存してからF8を使います。
対応  Windows IDEのHTML出力・CLIのweb

入力例
【index.kh】
use "style.kh"
page("工房", "")

【style.kh】
theme("#1e684d")

結果・動作
2つのファイルを同じフォルダーに置いて出力すると、工房ページに緑色のアクセントが付きます。

【ウェブ出力の制限】
書き方  index.html / 最大24ページ / セクションの入れ子は最大12段
トップページは1つ必要です。関連ファイルの読み込みは最大8階層・計32回で、循環参照はエラーになります。大きな出力には実行上限もあります。
対応  ウェブ出力。use はWindows IDE・CLI。

入力例
page("ホーム", "")
section("案内")
text("ここに本文を置きます。")
section_end()

結果・動作
トップページが1枚作られ、開いたセクションは出力前に閉じられます。

■ Windows IDEの操作

保存済みの .kh を選んで開きます。
対応  Windows IDE

サンプルのソースが編集欄に表示されます。

【保存】

現在の内容をUTF-8の .kh として保存します。初回は名前と保存先を指定します。
対応  Windows IDE

入力例

■ ブラウザー版IDEの操作
Windows・Mac・Linuxで使えます。ウェブページとコンソールにはそれぞれ編集欄があり、実行結果を同じ画面で確認できます。

【モードを選ぶ】
書き方  ウェブページ / コンソール
ウェブの見た目を見る場合は「ウェブページ」、say の出力を読む場合は「コンソール」を選びます。
対応  ブラウザー版IDE

入力例
コンソール → say "こんにちは"

結果・動作
実行結果に「こんにちは」と表示されます。

【実行】
書き方  実行 / Ctrl + Enter / ⌘ + Enter
現在のコードを実行します。キーボード操作は編集欄で使えます。
対応  ブラウザー版IDE

入力例
ウェブページ → page("こんにちは", "") → 実行

結果・動作
実行結果の領域にページが表示されます。

【リセット】
書き方  リセット ボタン
現在のモードのコードを最初のサンプルに戻します。
対応  ブラウザー版IDE

入力例
コンソール → リセット

結果・動作
コンソールの初期サンプルが表示されます。

【コピー】
書き方  コピー ボタン
現在のコードをクリップボードにコピーします。
対応  ブラウザー版IDE

入力例
コピー → 任意のテキストエディターに貼り付ける

結果・動作
入力したコードを貼り付けられます。

【.kh を開く】
書き方  .kh を開く ボタン
UTF-8で保存した .kh を現在のモードで開きます。
対応  ブラウザー版IDE

入力例
ウェブページ → .kh を開く → index.kh

結果・動作
ファイルの中身が編集欄に表示されます。

【.kh を保存】
書き方  .kh を保存 ボタン
現在のコードをUTF-8の .kh としてダウンロードします。
対応  ブラウザー版IDE

入力例
コードを書く → .kh を保存

結果・動作
現在のファイル名で .kh を保存できます。

【HTMLを保存】
書き方  HTMLを保存 ボタン
ウェブページモードでコードを実行し、生成したページを単一のHTMLとして保存します。
対応  ブラウザー版IDE

入力例
ウェブページ → HTMLを保存

結果・動作
スタイルとボタンの動作を含んだ .html が保存されます。

■ Mac・Linux向けCLI
macOSではCコンパイラーとmakeでビルドします。Linux x64では同梱の ./linux-x64/kh も使えます。下の例は、配布ZIPの展開先で実行します。

【ビルド】
書き方  make
同梱のCソースからターミナル用の kh を作ります。
対応  Mac・Linux向けCLI

入力例
make

結果・動作
カレントフォルダーに kh が作成されます。

【run】
書き方  ./kh run script.kh
コンソール向け .kh を実行し、say の結果をターミナルに出します。
対応  Mac・Linux向けCLI

入力例
./kh run examples/Console/Hello.kh

結果・動作
日本語のあいさつなど、スクリプトが出力した内容を確認できます。

【web】
書き方  ./kh web index.kh 出力先
ウェブ向け .kh から公開用サイトを生成します。出力先には新しいフォルダー名を指定します。
対応  Mac・Linux向けCLI

入力例
./kh web examples/Website/index.kh my-site

結果・動作
my-site に index.html、about.html、styles.css、app.js ができます。

【--version】
書き方  ./kh --version
使っているCLIのバージョンを表示します。
対応  Mac・Linux向けCLI

入力例
./kh --version

結果・動作
KH 0.3

【--help】
書き方  ./kh --help
CLIで使う主なコマンドと書式を表示します。
対応  Mac・Linux向けCLI

入力例
./kh --help

結果・動作
run、web、--version の使い方が表示されます。
